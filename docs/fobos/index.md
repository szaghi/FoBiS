# fobos keys

A `fobos` file is the project's build configuration, in INI syntax: one section per mode (a build configuration),
plus the special sections below. `fobis` reads `./fobos`, or the file given with `-f`/`--fobos`. A mode key has the
name of a command-line option without the leading `--` and with underscores (`--build-dir` is `build_dir`); a key
FoBiS does not know is ignored without a warning, so check the spelling against [every mode key](#every-mode-key).
A value runs to the end of the line: a `;` or `#` after it is part of the value, and FoBiS warns about it.

How to write one, with examples: [Building](/cookbook/build#write-a-fobos).

Any key can be qualified, `key.QUALIFIER`, and applies only when QUALIFIER is the mode's compiler (`gnu`, `intel`, `intel_nextgen`, `g95`, `opencoarrays-gnu`, `pgi`, `ibm`, `nag`, `nvfortran`, `amd`, `lfortran`, `custom`) or the operating system (`linux`, `macos`, `windows`, `freebsd`): `cflags`, `lflags`, `preproc`, `c_cflags`, `c_preproc` get the value appended (compiler, then system), any other key is replaced. An unknown qualifier, or one key replaced by both a compiler and a system key, is an error. See [flags that differ by compiler or system](/cookbook/build#flags-that-differ-by-compiler-or-system).

# User configuration

The settings of the machine, not of a project: the language model, the ecosystem of projects, the Slurm
scheduler. FoBiS reads `$XDG_CONFIG_HOME/fobis/config.ini` (`~/.config/fobis/config.ini` when the variable is
unset). A project's fobos holds the project's settings; for `[scheduler]`, a fobos section adds to the user's, key
by key.

```bash
fobis commit --init-config     # write the commented file below, where it is missing
fobis commit --show-config     # the LLM settings in effect
```

Every value shown is the default; uncomment a line to change it. Guides: [local models](/ai/models),
[ecosystem](/advanced/ecosystem), [running on a cluster](/advanced/scheduler).

## Environment variables

| Variable | Effect |
|---|---|
| `XDG_CONFIG_HOME` | Where the user configuration and the user's knowledge packs are (`~/.config` when unset) |
| `FOBIS_LLM_DIR` | The model store and the llama.cpp runtime (default `~/.fobis/llm`) |
| `HF_TOKEN` | A Hugging Face token, for gated models; sent to the Hub only, never to the download CDN |
| `HF_ENDPOINT` | A Hugging Face mirror |
| `FOBIS_CACHE_DIR` | The build cache (default `~/.fobis/cache`) |
| `XDG_CACHE_HOME` | Where `fobis ecosystem dashboard --format html` writes its page (`~/.cache` when unset) |
| `EDITOR` | The editor of `fobis merge-assist --apply` (`e`) |
| `LOADEDMODULES` | Read, not set: recorded in the provenance of results (environment modules) |
| `OMP_NUM_THREADS` | Read, not set: recorded in the provenance; set by a case's `threads` |

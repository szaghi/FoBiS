# `case` command

List and run the cases declared in the fobos (`[case:NAME]` sections). Guide:
[Cases, quantities and provenance](/advanced/cases).

```bash
fobis case list [options]
fobis case run [NAME...] [options]
```

## `case list`

| Option | Description |
|--------|-------------|
| `--json` | The cases as JSON |
| `-f/--fobos`, `--fci` | The fobos file |

## `case run`

Build (for a `target`) and run each case (all by default) in a fresh run directory, and report its quantities.

| Option | Description |
|--------|-------------|
| `--mode M` | Build with this mode instead of the case's own |
| `--shadow NAME` | Rebuild the mode as a [shadow](/advanced/matrix#shadow-modes): `checks`, `sanitize`, `strict` (or `none`), in `.fobis/shadow/<mode>-<shadow>/` |
| `--runner local\|slurm` | Run the programs locally (default) or as Slurm jobs (see [Running on a cluster](/advanced/scheduler)) |
| `--json` | One JSON object: `results`, each with status, exit code, elapsed time, command, run directory, quantities, probe errors, output tails, provenance and, when the build failed, the build's diagnoses |
| `-f/--fobos`, `--fci` | The fobos file |

## Exit codes

| Code | Meaning |
|------|---------|
| 0 | Every run is `ok` |
| 1 | A run failed, timed out, did not build or missed a quantity |
| 2 | A case is declared incorrectly, or an unknown case is named |

## All options

### `fobis case list`

| Option | Value | Default | Description |
|---|---|---|---|
| `--fobos`, `-f` | TEXT |  | Specify a "fobos" file named differently from "fobos" |

### `fobis case run`

Build and run cases; report their quantities, the status of each run and its provenance.

Arguments: `NAMES...`

| Option | Value | Default | Description |
|---|---|---|---|
| `--fobos`, `-f` | TEXT |  | Specify a "fobos" file named differently from "fobos" |
| `--fci` |  |  | Assume fobos inputs as case insensitive |
| `--mode` | TEXT |  | Select a mode defined into a fobos file |
| `--shadow` | TEXT |  | Rebuild the mode as a shadow (checks, sanitize or strict): the mode's settings with checking flags, in its own build directory (.fobis/shadow/&lt;mode&gt;-&lt;shadow&gt;/). |
| `--runner` | TEXT | `local` | Where the programs run: local, or slurm (jobs submitted with sbatch; [scheduler] settings). |

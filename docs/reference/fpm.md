# `fpm` command

Translate between an `fpm.toml` and a fobos. Guide: [fpm interoperability](/advanced/fpm).

```bash
fobis fpm import [options]
fobis fpm export [options]
```

| `import` option | Description |
|--------|-------------|
| `--fpm FILE` | The manifest to read [default: `fpm.toml`] |
| `-o/--output FILE` | The fobos to write [default: `fobos`] |
| `--compiler NAME` | Compiler of the generated modes [default: `gnu`] |

| `export` option | Description |
|--------|-------------|
| `-o/--output FILE` | The manifest to write [default: `fpm.toml`] |
| `--mode M` | The mode whose sources, MPI/OpenMP and macros are exported [default: the first] |
| `-f/--fobos`, `--fci` | The fobos file |

Both: `--force` (overwrite), `--print` (print, write nothing), `--json` (`written`, `text`, `notes`). Exit code 0;
2 when the output exists without `--force`, the input is missing or unreadable.

## All options

### `fobis fpm export`

Write an fpm.toml for the project: metadata, the library directory (where the modules are), executables and tests (where the programs are), git dependencies, MPI/OpenMP metapackages, macros; notes for the rest.

| Option | Value | Default | Description |
|---|---|---|---|
| `--output`, `-o` | TEXT | `fpm.toml` | The fpm manifest to write. |
| `--fobos`, `-f` | TEXT |  | Specify a "fobos" file named differently from "fobos" |
| `--fci` |  |  | Assume fobos inputs as case insensitive |
| `--mode` | TEXT |  | Select a mode defined into a fobos file |
| `--force` |  |  | Overwrite the output file when it exists. |
| `--print` |  |  | Print the translation; write nothing. |
| `--json` |  |  | Emit structured JSON to stdout instead of human-readable output (useful for scripting / agents) |

### `fobis fpm import`

Write a fobos for an fpm package: sources, one mode per profile with fpm's flags for the compiler (features as [feature:NAME] sections), lib-static/lib-shared modes, tests, git, path and dev dependencies, macros, libraries; notes for the rest.

| Option | Value | Default | Description |
|---|---|---|---|
| `--fpm` | TEXT | `fpm.toml` | The fpm manifest to read. |
| `--output`, `-o` | TEXT | `fobos` | The fobos to write. |
| `--compiler` | TEXT | `gnu` | FoBiS compiler of the generated modes: fpm's flags for it are translated. |

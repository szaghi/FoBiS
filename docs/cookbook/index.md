# Cookbook

Everything FoBiS does, by task. Each chapter opens with how that part of FoBiS works, then gives one recipe per task:
the fobos lines, the commands, a real output, the limits worth knowing, and links to the tutorial chapter that shows
it running and to the reference of every option. Every output on these pages is generated by the tutorials' sessions
and checked by CI; every `fobis` command and fobos mode key is checked against FoBiS itself.

New to FoBiS? Start with the [first tutorial](/tutorial/first-steps/01-first-build): it builds a project in five
minutes. Come back here when you need something specific.

| Chapter | What it covers |

| [Dependencies](./dependencies) | a GitHub dependency pinned or in a semver range, built with your sources or as a library, a local directory, test-only dependencies, the lock file, installing from GitHub, offline machines |

| [Verifying results](./verification) | cases and the quantities they print, references and tolerances, checked builds across compilers, numerical error, whether a change is harmless or faster, the gate, profiles |
| [Code quality](./analysis) | the linter, legacy code, suppressions and fixes, reviews of a change, who calls what, verified modernisation, C and Python bindings |
| [AI assistance](./ai) | explained build failures and crashes, questions about the code, generated tests, a second reader, commit messages, merge conflicts, what to trust |

| [HPC and clusters](./hpc) | MPI, OpenMP and GPU builds, several compilers, launchers, Slurm, profiling on a node, air-gapped machines |
